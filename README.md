# Разлиновка A4

[Открыть форму для печати](https://www.zaverden.com/a4/)

Форма для печати листов A4 в клетку или в линейку. Можно включить горизонтальные и вертикальные линии по отдельности, задать шаг, толщину, прозрачность и отступы, а также разместить 1, 2 или 4 блока на листе.

1. Выберите шаблон и настройте разлиновку по предпросмотру.
2. Нажмите **Печать / PDF**. В диалоге печати выберите формат **A4** и масштаб **100%**.
3. Отправьте лист на принтер или сохраните его как PDF.

Форма состоит из одного файла `index.html`, который можно открыть в браузере и без интернета. Последние настройки сохраняются в браузере. Кнопка **Сбросить настройки** возвращает исходные значения.
