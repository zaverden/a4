# Разлиновка A4

[Открыть форму для печати](https://www.zaverden.com/a4/)

Форма для печати листов A4 в клетку или в линейку. Можно включить горизонтальные и вертикальные линии по отдельности, задать шаг, толщину, прозрачность и отступы, а также разместить 1, 2 или 4 блока на листе.

1. Выберите шаблон и настройте разлиновку по предпросмотру.
2. Нажмите **Печать**, чтобы открыть диалог печати векторного PDF. Выберите бумагу **A4** и масштаб **100%**.
3. Если браузер не открыл диалог, воспользуйтесь ссылкой под кнопками, чтобы открыть PDF в новой вкладке и напечатать его оттуда.

Кнопка **Скачать PDF** сохраняет тот же векторный файл.

Ползунки шага, толщины и отступов показывают миллиметры и точки. В режиме **Сетка 600 dpi** значения меняются на одну точку, а края линий выравниваются по сетке. Для этого режима печатайте в масштабе **100%** при **600 dpi**. В режиме **Миллиметры** шаг и отступы меняются на 0,5 мм, а толщина на 0,05 мм.

Значения можно ввести вручную в полях рядом с ползунками. При переключении режима текущие размеры округляются до ближайшего допустимого значения в выбранных единицах.

Шаг измеряется между левыми краями соседних вертикальных линий и между верхними краями соседних горизонтальных линий. При шаге 5 мм и толщине 0,2 мм просвет между линиями составляет 4,8 мм.

Форма состоит из одного файла `index.html`, который можно открыть в браузере и без интернета. Последние настройки сохраняются в браузере. Кнопка **Сбросить настройки** возвращает исходные значения.
